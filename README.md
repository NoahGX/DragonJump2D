# DragonJump2D
 
This project is a beginner-friendly, 2D-platform video game where players control a small dragon character as it navigates a side-scrolling environment, avoiding obstacles, engaging with simple enemies, and launching fireballs as a primary attack. The gameplay evolves gradually—starting with movement and jumping, then progressing to enemy interactions, projectile combat, and audio effects. The game supports real-time collisions, prefab instantiation (for fireballs and enemies), and WebGL deployment, allowing it to be played directly in a web browser.
